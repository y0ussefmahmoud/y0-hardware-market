# 🚨 URGENT FIX PROMPT: REMOVE INFINITE SPINNER & FIX AUTH USER STATE

## 📌 Context & Problem Diagnosis

* **Project:** Y0 Hardware Market (PC Builder & Silicon Ecommerce Platform)
* **The Bug:** 
  1. The cyan spinner in the header next to the cart stays stuck loading (`isLoading = true` infinite loop), meaning the user session check (`/api/auth/me`) never resolves or fails to set `isLoading: false`.
  2. Because the spinner never finishes, the actual "Login / Register" or "User Account Profile" button is never rendered!

### Step 2: Implement Clean & Direct Fallback Rendering in `Header.tsx`

Replace the header account node section with this robust, non-blocking logic:

```tsx
// Inside Header component rendering
{isLoading ? (
  /* Static minimal fallback button while hydrating - NO INFINITE LOADER */
  <a
    href={`/${locale}/auth/login`}
    className="flex items-center gap-1.5 px-3 py-1.5 rounded-lg bg-surface-container-high/60 border border-outline-variant/30 text-on-surface hover:text-primary-container text-xs font-bold transition-all"
  >
    <span className="material-symbols-outlined text-[18px]">account_circle</span>
    <span>Login</span>
  </a>
) : user ? (
  /* Authenticated User State */
  <a
    href={user.role === 'admin' ? `/${locale}/admin` : `/${locale}/account`}
    className="flex items-center gap-2 px-3 py-1.5 rounded-lg bg-primary-container/20 border border-primary-container/40 text-primary-container hover:bg-primary-container/30 text-xs font-bold transition-all z-20"
  >
    <span className="material-symbols-outlined text-[18px]">account_circle</span>
    <span className="max-w-[100px] truncate">{user.first_name || user.name || 'Account'}</span>
    {user.role === 'admin' && (
      <span className="bg-cyan-500/20 text-cyan-400 text-[10px] px-1.5 py-0.5 rounded uppercase border border-cyan-500/30 font-mono">
        Admin
      </span>
    )}
  </a>
) : (
  /* Guest State (Not Logged In) */
  <div className="flex items-center gap-2">
    <a
      href={`/${locale}/auth/login`}
      className="flex items-center gap-1.5 px-3 py-1.5 rounded-lg bg-surface-container-high border border-outline-variant/30 text-on-surface hover:text-primary-container hover:border-primary-container/50 text-xs font-bold transition-all z-20"
    >
      <span className="material-symbols-outlined text-[18px]">person</span>
      <span>Login</span>
    </a>
  </div>
)}
```
