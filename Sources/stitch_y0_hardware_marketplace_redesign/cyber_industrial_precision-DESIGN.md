## Brand & Style

The design system embodies a **Cyber-Industrial Precision** aesthetic engineered for elite PC builders, hardware enthusiasts, system integrators, and competitive gamers. It bridges the deep, spec-dense telemetry of an industrial hardware diagnostic workbench with the rapid, zero-friction conversion flow of modern enterprise commerce.

### Brand Tone & Persona
- **Surgical Accuracy:** Layouts prioritize granular specifications, raw throughput metrics, benchmarks, and exact dimension clearances over decorative fluff.
- **Aggressive Performance:** High-contrast luminescence against deep obsidian fields, evoking custom liquid cooling loops, high-end silicon dies, and illuminated server racks.
- **Uncompromised Trust:** Rock-solid structural grids, deterministic feedback, and immediate inventory transparency.

### Visual Styling Mechanics
- **Base Canvas:** Obsidian vacuum (`#090D16`), engineered to mitigate eye strain during long-session system configuration while delivering infinite black levels for luminous UI accents.
- **Luminescence Strategy:** Electric Cyan (`#00F2FE`) acts as the high-velocity operational lead (conversion hooks, primary CTAs, active selectors), counterbalanced by Plasma Violet (`#7C3AED`) for prestige indicators, overclocking tiers, and high-frequency badges.
- **Tactile Boundaries:** Structural segmentation relies on razor-thin 1px frosted boundaries (`rgba(255, 255, 255, 0.08)`) with targeted micro-glows rather than heavy drop shadows, reinforcing a chassis-milled physical feel.

## Colors

The palette is anchored in an uncompromising deep dark mode, utilizing precision luminescence across functional layers.

### Canvas & Surfaces
- **Canvas Base:** `#090D16` (Deep Obsidian Vacuum) — Global backdrop.
- **Surface Level 1:** `#0F172A` (Milled Alloy Slate) — Master cards, technical shelves, sticky utility bars.
- **Surface Level 2:** `#1E293B` (Cold Anodized Slate) — Interactive containers, active drawer segments, spec table alternating zebra fills, chip wells.
- **Surface Level 3:** `#334155` (Elevated Matrix) — Hover states, popovers, tooltip surfaces.

### Accents & Energetics
- **Primary (Electric Cyan):** `#00F2FE` — Conversion pathing, active bus routes, high-priority interactions, system telemetry highlights.
- **Secondary (Plasma Violet):** `#7C3AED` — Enthusiast hardware tiering, bundles, AI compute indicators, overclocking profiles.
- **Tertiary / Success (Cyber Emerald):** `#10B981` — Verified in-stock indicators, benchmark superiority, active inventory status.

### Functional Alerts & Status
- **Critical / Hot Deals:** `#EF4444` (Laser Crimson) — Low stock warnings, thermal throttle alerts, instant discount bursts, out-of-stock lockouts.
- **Caution / Warning:** `#F59E0B` (Amber Protocol) — Backorder reservations, power supply overhead alerts, BIOS compatibility notices.

### Text & Telemetry Contrast
- **Text High-Contrast:** `#F8FAFC` — Primary titles, hardware designations, metric readouts.
- **Text Muted / Metric:** `#94A3B8` — Technical labels, architecture metadata, form labels.
- **Borders & Seams:** `rgba(255, 255, 255, 0.08)` — Frosted structural delimiters.
- **Border Active Focus:** `rgba(0, 242, 254, 0.5)` — Focused input fields, active component sockets.

## Typography

The typographic hierarchy implements an engineering-led tri-font matrix:
1. **Primary Structural Text (Inter):** High-density legibility for product nomenclature, promotional storytelling, marketing headers, and transactional form interfaces.
2. **Technical Telemetry & Currencies (JetBrains Mono):** Clock speeds (GHz), memory timings (CL30), thermal envelopes (TDP), benchmark framerates, part SKUs, and EGP (Egyptian Pound) price structures. Tabular numbers (`tnum`) must be enforced across all price columns and stock counter readouts.
3. **Bilingual Regional Support (Cairo):** For Arabic locale presentations, Cairo binds dynamically to all Inter tiers, maintaining line-height parity and proportional optical weight for seamless RTL layout transitions.

### Styling Rules
- **Component Nomenclature:** Brand headers always lock to uppercase prefixes when indicating hardware chipsets (e.g., `RTX 4090 OC`, `DDR5-6000MHz`).
- **Telemetry Tags:** Product SKUs and technical data badges must use `label-sm` or `spec-code-sm` with explicit uppercase transforms and tracked-out letter spacing.
- **Price Displays:** Always render currency prefixes in `spec-code-md` and main numerical values in `spec-code-lg` with tabular figures enabled.

## Layout & Spacing

The layout model is built on an ultra-precise 8px baseline rhythm (with a 4px half-step sub-grid for dense hardware spec matrices).

### Grid Configuration
- **Desktop (>= 1280px):** 12-column fluid grid, `margin-desktop` (3rem / 48px), `gutter-desktop` (1.5rem / 24px). Max container width locks at 1600px for ultra-wide hardware workstations.
- **Tablet (768px - 1279px):** 8-column fluid grid, `margin-tablet` (2rem / 32px), `gutter` (1rem / 16px).
- **Mobile (< 768px):** 4-column fluid grid, `margin` (1rem / 16px), `gutter` (0.75rem / 12px).

### High-Density Layout Rules
- **Technical Tables & Parametric Filters:** Use compact vertical padding (`space-xs` to `space-sm`) to ensure maximum visible data density above the fold.
- **Component Cards:** Inner content grouping uses `space-sm` between spec chips and titles, and `space-md` between functional blocks (Media -> Telemetry Specs -> Conversion Shelf).
- **Reflow Logic:** For mobile screens, multi-metric comparison matrices collapse into horizontal swipe rails with left-locked parameter headers.

## Elevation & Depth

Visual hierarchy does not rely on diffuse, generic drop shadows. Instead, it utilizes **Alloy Layering** and **Luminescent Voltage Planes**:

### Tiers of Depth
- **Ground Floor (Base Canvas, `#090D16`):** Absorbs light. Houses the master layout grid and inactive backgrounds.
- **Tier 1 (Chassis Panels, `#0F172A`):** 1px frosted boundary `rgba(255, 255, 255, 0.08)`. Default state for cards, filter panels, and comparison sidebars.
- **Tier 2 (Active Modules, `#1E293B`):** 1px frosted boundary `rgba(255, 255, 255, 0.12)`. Applied to dropdowns, modal windows, table header strips, and hover states.
- **Tier 3 (Floating HUD / Overlays, `#0F172A` at 90% opacity with `backdrop-filter: blur(12px)`):** Fixed navigation bars, floating quick-cart summaries, and configuration totalizers.

### Glow & Voltage Tokens
- **Cyan Resonance:** `0 0 20px -3px rgba(0, 242, 254, 0.25)` — Applied on primary action buttons, active component selector cards in PC builders, and critical focus states.
- **Violet Core:** `0 0 24px -4px rgba(124, 58, 237, 0.3)` — Applied on exclusive hardware drops, high-tier enthusiast badges, and bundle promotions.
- **Crimson Alert:** `0 0 16px -2px rgba(239, 68, 68, 0.35)` — Flashed on deal timer tickers and stock depletion alerts.

## Shapes

The design system employs a **Micro-Chamfered Industrial Radius** (`roundedness: 1` — base `0.25rem` / 4px). 

Roundedness options and implementations:
- **Base Components (Inputs, Buttons, Badges, Chips):** `0.25rem` (4px). Replicates precision laser-cut sheet metal and CNC-milled PC chassis interfaces.
- **Component Enclosures & Cards (`rounded-lg`):** `0.5rem` (8px). Maintains structure without introducing organic or toy-like curves.
- **Modal Windows & Canvas Drawers (`rounded-xl`):** `0.75rem` (12px).
- **Prohibitions:** Circular pill shapes are strictly forbidden for actionable buttons and badges; pill contours violate the industrial, technical computing aesthetic. True circles are reserved exclusively for status ping avatars and color swatch selectors.

- **Image Staging:** High-contrast dark bay (`#090D16`) with a subtle technical crosshair grid watermark.
- **Spec Matrix Strip:** Micro-table displaying 3 key technical metrics (e.g., Boost Clock, VRAM, TDP) in `JetBrains Mono`.

- **Hover State:** Card translates -2px on the Y-axis; outer border transitions to `rgba(0, 242, 254, 0.4)` accompanied by a low-opacity cyan perimeter glow.

### 4. Technical Data Tables & Benchmark Bars
- **Table Cells:** Alternating row fills with `#0F172A` and `#141E33`. Borders are thin horizontal rules (`1px solid rgba(255, 255, 255, 0.05)`).

- **Checkbox & Radio Controls:** Square (4px radius) or octagon-profile radio, dark field `#090D16`, active fill `#00F2FE` with contrasting obsidian check glyph.
